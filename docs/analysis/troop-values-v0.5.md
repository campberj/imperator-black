# Troop values — content v0.5.0

Generated by `app/src/Imperator.Sim --values`. Monte Carlo runs: 20,000 per measure per profile, seed 1. Regenerate with `dotnet run -c Release --project app/src/Imperator.Sim -- --values docs/analysis/troop-values-v0.5.md`.

Every troop profile in `content/troops.yaml`, with its default loadout (armour, weapon, melee weapon, gear), against the reference trooper, the VAT Assaulter (`tfb_vat_assaulter`). These are data for calibrating troop values (decision 6.12); the points formula comes after.

- **Duel 12"**: both models in the open at 12". Each round, initiative (2d6, plus Nerve for a Leader) decides who activates first. Each activation is Aim then Shoot; a model with Suppression Rallies in place of Aim, and a Pinned model in the open (which may not Shoot) Rallies again unless the first Rally unpinned it. The first to put the other Down or worse wins. A Shield counts as Light cover.
- **Duel 24" cover**: the same at 24", both models in Light cover; end-of-round recovery applies.
- **Close combat**: the exchange rules of chapter 5, a coin deciding who charges, both using the default break rule (break only after losing while Wounded or at 3+ Suppression; it ends only if both break).
- **Score**: the mean of the three win rates. A draw (both broke away, or no result after 30 rounds) counts as half a win. The reference scores 50% against itself.
- **Rows A0 / A2 / A3**: expected total wound rows from one aimed Shoot at 12" against fresh targets in the open with Armour 0, 2 and 3 (a miss or no effect counts 0, rows cap at 10). An *Auto N* weapon engages N targets, −1 after the first. *Suppressing* adds Suppression, not rows, so it does not show here.
- No grenades, Moves or reactions. † Automated. \* has a Proposed skill. N/A: no ranged weapon (its score is close combat alone).
