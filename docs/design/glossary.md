# Glossary

Working definitions. Rules text uses these terms exactly; when a definition changes, update it here first.

| Term | Definition |
|---|---|
| **Action** | One thing a model does during an activation (Move, Shoot, Aim, Suppressive Fire, Overwatch, Find Cover, Rally, Medic, Interact). A model has two per activation. |
| **Activation** | One model's turn to act. Players alternate activating single models. |
| **Activated** | A model that has activated this round, or has reacted (which marks it activated). |
| **Alert track** | A 0–6 mission track raised by noise. Thresholds trigger contact movement, the enemy reaction force and lockdown. |
| **AP** | Armour piercing. Reduces the target's Armour before it steps the wound row down. |
| **Armour** | 0–3. Steps the wound-table row down by that many rows, less AP. |
| **Breaking** | When half a fireteam (rounded up) is Down or Dead, each remaining model tests at the start of its activation or falls back. |
| **Casualty shock** | Suppression gained when a nearby friendly model goes Down or Dead. |
| **Contact** | An unrevealed enemy token. Rolled on the mission's contact table when revealed. |
| **Cover (Light / Heavy)** | Light: at least a third of the body hidden (−1 to hit). Heavy: at least half hidden behind solid material (−2). |
| **Critical hit** | A natural double 6 on the hit roll. Adds one row to the wound result. |
| **Damage dice** | The weapon's dice pair (2d4 to 2d12), thrown with the hit dice and counted only on a hit. |
| **Element** | An enemy type with its own stats and behavior profile (e.g. Guards, Enforcers). |
| **Fireteam** | The smallest sub-unit, usually 4–6 models including a leader. |
| **Hit dice** | The 2d6 thrown to hit. |
| **Keyword** | A weapon trait with a rules effect (e.g. *Handy*, *Auto*). |
| **Overwatch** | An action that lets a model react up to two times before its next activation. |
| **Pinned** | A model with 3 or more Suppression. Limited to Rally, Find Cover, Move to cover, or Shoot from cover. |
| **Quality (Q)** | 0–3 (Green, Regular, Veteran, Elite). Added to hit rolls and tests. |
| **Reaction** | An action taken out of turn in response to an enemy action. Available to models not yet activated, and to models on Overwatch. |
| **Round** | Initiative, then every model activates once, then end-of-round steps. |
| **Short range** | A weapon's effective distance. Beyond it −1, beyond double −2. Weapons have no maximum range. |
| **Suppression** | Markers that give −1 to all rolls each (maximum 5). Removed by Rally and by staying unhit in cover. |
| **Test** | 2d6 + Q (minus Suppression) against a target number. |
| **Threat tier** | 1–4. Sets which enemy elements a mission can draw on. |
| **Wound table** | Ten rows keyed to the damage total, from Shaken (row 1) to Dead (rows 9–10). |
