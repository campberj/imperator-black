# Generated missions

Missions made by `tools/generate_mission.py` (rules chapter 13) from the seed in the file name. Print with
`python3 tools/print_scenario.py docs/scenarios/missions/<file>.yaml`; the sheet (with the dashboard as its
last page) and the cards go to `docs/print/missions/`.

| File | Mission | Where | Tier |
|---|---|---|---|
| `mission-ship-42.yaml` | Capture a high-value target | Freighter, deck 42 (the chapter 13 example) | 1 |
| `mission-land-11.yaml` | Seize data or cargo | Desert, 36" × 36" | 3 |

The player force is not part of a generated mission: bring the team (up to 8 models for a small mission).
