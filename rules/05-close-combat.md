# 5. Close combat

Close combat aboard ship is short, brutal and decisive. Once it starts, it does not stop until someone is out of the fight or both sides choose to pull apart.

## Starting close combat

A model starts close combat by **Moving into base contact** with an enemy model. This is a Move, so it can trigger reactions: the target, if it is unactivated or on Overwatch, may react before contact (for example, by shooting at −1 at any point during the approach).

If the model moved at least 1" before making contact, it is **charging**.

## Resolving close combat

Close combat resolves **immediately**, in a series of **exchanges**, without spending more actions. When it ends, the activating model may use its remaining action, if it has one and is still standing.

### An exchange

1. Both models roll **2d6 + Q** and apply modifiers.
2. The **higher total wins**. On a tie, both models gain 1 Suppression and nothing else happens.
3. The winner throws its **melee weapon's damage dice** and reads the wound table, stepping down by the loser's Armour less AP, exactly as for shooting. A natural double 6 on the exchange roll is a critical hit (+1 row).
4. If the wound result has no effect, the loser still gains **1 Suppression**.

| Close combat modifier | Value |
|---|---|
| Charging (first exchange only) | +1 |
| Each friendly model also in base contact with the enemy (maximum +2) | +1 |
| Each Suppression marker | −1 |
| Wounded | −1 |
| Unbraced in zero-g (not *Void-trained*) | −1 |

### Overpowered

A model with **5 Suppression** that loses an exchange is **overpowered**. It goes Down, or, if the winner chooses and the mission allows prisoners, it is **captured**.

### Continue or break away

After each exchange, if neither model is incapacitated (Down, Dead, captured or surrendered), each side declares **Continue** or **Break**. The loser of the exchange declares first.

- If **both** declare Break, the combat ends. Each model moves 1" directly away from the other, loser first.
- Otherwise, fight another exchange.

The charge bonus applies only to the first exchange.

## More than two models

When a model moves into contact with an enemy that is touching other models, or touches more than one enemy:

- The moving model fights **one** enemy model it touches; its player chooses which.
- Every other model in base contact with that enemy adds +1 to its side (maximum +2) but does not roll.
- Models not fighting are not harmed by the exchanges.

## Solo opponent

Until behavior profiles are written: an enemy model declares Break if it lost the last exchange and is Wounded or has 3 or more Suppression; otherwise it Continues.
